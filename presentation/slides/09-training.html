def lr_lambda(step):
  if step < warmup_steps:
    return (step + 1) / warmup_steps
  progress = (step - warmup_steps) / (total_steps - warmup_steps)
  return 0.5 * (1 + math.cos(math.pi * progress))

برای آموزش از AdamW با نرخ یادگیری پنج ده‌هزارم و weight decay یک‌صدم استفاده کردم. نرخ یادگیری ثابت نیست: تابع lr_lambda در شش درصد اول گام‌ها نرخ را به‌صورت خطی از نزدیک صفر تا مقدار اصلی بالا می‌برد، که همان warmup است، و بعد با یک منحنی کسینوسی تا صفر پایین می‌آورد. warmup برای ترنسفورمر مهم است، مخصوصاً با ساختار Post-LN، چون در گام‌های اول وزن‌ها تصادفی‌اند و گرادیان‌ها بزرگ و پرنویزند و نرخ یادگیری بزرگ می‌تواند آموزش را خراب کند. زمان‌بند بعد از هر گام به‌روز می‌شود نه بعد از هر اپوک. در حلقه‌ی آموزش، بعد از backward، نرم گرادیان‌ها به حداکثر یک محدود می‌شود تا یک batch بد باعث جهش وزن‌ها نشود. هر اپوک ۱۷۸۲ گام است و روی CPU چهار هسته‌ای حدود شش و نیم دقیقه طول می‌کشد؛ کل شش اپوک حدود ۳۹ دقیقه. بعد از هر اپوک روی داده‌ی اعتبارسنجی ارزیابی می‌کنم و اگر دقت اعتبارسنجی بهتر شد وزن‌ها را ذخیره می‌کنم؛ ارزیابی نهایی روی تست با همین بهترین وزن‌ها انجام می‌شود.
