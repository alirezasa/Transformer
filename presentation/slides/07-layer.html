‫روی هر توکن جداگانه: 128 → 256 → 128 با GELU؛ غیرخطی بودن مدل از اینجاست.

class PositionwiseFeedForward(nn.Module):
  def forward(self, x):
    return self.fc2(self.dropout(F.gelu(self.fc1(x))))

class EncoderLayer(nn.Module):
  def forward(self, x, key_mask=None):
    attn_out, attn = self.self_attn(x, key_mask)
    x = self.norm1(x + self.drop1(attn_out))
    x = self.norm2(x + self.drop2(self.ffn(x)))
    return x, attn

class TransformerEncoder(nn.Module):
  def forward(self, input_ids, key_mask=None):
    x = self.pos_encoding(self.embedding(input_ids))
    for layer in self.layers:
      x, attn = layer(x, key_mask)

هر لایه‌ی کدگذار دو زیرلایه دارد. اولی همان توجه چندسر است. دومی شبکه‌ی پیش‌خور موقعیت‌به‌موقعیت است: دو لایه‌ی خطی که بردار هر توکن را جداگانه از ۱۲۸ به ۲۵۶ بعد می‌برند، GELU می‌زنند و به ۱۲۸ برمی‌گردانند. توجه فقط یک ترکیب خطی وزن‌دار از بردارهاست، پس غیرخطی بودن مدل از همین FFN می‌آید. دور هر زیرلایه یک اتصال باقیمانده و یک LayerNorm هست. من ساختار Post-LN مقاله‌ی اصلی را پیاده کردم: اول خروجی زیرلایه، بعد از dropout، با ورودی جمع می‌شود و بعد LayerNorm اعمال می‌شود. دو خط وسط کد دقیقاً همین است. اتصال باقیمانده باعث می‌شود گرادیان مسیر مستقیمی تا لایه‌های پایین داشته باشد. LayerNorm هم روی بعد ویژگیِ هر توکن نرمال می‌کند و به اندازه‌ی batch یا طول جمله وابسته نیست؛ به همین دلیل در ترنسفورمرها از آن استفاده می‌شود نه BatchNorm. Post-LN در شروع آموزش کمی ناپایدارتر از Pre-LN است، برای همین warmup نرخ یادگیری و gradient clipping گذاشتم. کلاس TransformerEncoder هم فقط این‌ها را به هم وصل می‌کند: امبدینگ، کدگذاری موقعیت و حلقه روی N لایه، و وزن‌های توجه هر لایه را هم در یک لیست نگه می‌دارد.
